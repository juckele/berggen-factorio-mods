Version: 1.1.0
Date: 2026-10-26
  Features:
    - Colour setting for the anti-jam stack inserter: purple, aqua, magenta or black. Automatic is purple,
      or black when the Long-handed stack inserter mod is installed.
    - With the Long-handed stack inserter mod: a long-handed anti-jam stack inserter, in every item mode,
      with its own colour setting (automatic: aqua) and an optional recolour of the long-handed stack
      inserter itself.
    - "Yellow hand" settings: keep the stack inserter's yellow hand and only recolour the platform and arm,
      like the long-handed stack inserter. On by default for every inserter when that mod is installed;
      off (full recolour) otherwise.
  Changes:
    - The anti-jam stack inserter is now the bulk inserter's default upgrade (upgrade planner with no rules),
      and downgrades to it. Can be turned off with a startup setting. Stack inserters still don't upgrade
      or downgrade.

Version: 1.0.0
Date: 2026-10-23
  Features:
    - Anti-jam stack inserter: a stack inserter that swings without waiting for a full hand.
    - Startup setting "Item mode":
      - Smart swapping (default): built from and mined to stack inserter items; place it with an upgrade
        planner, blueprint, ghost or pipette. Switching a save to it turns existing anti-jam stack inserter
        items back into stack inserters.
      - Distinct item: its own item with the stack inserter's recipe.
      - Distinct item with quick swap: plus quick conversion recipes between stack and anti-jam stack inserters.
